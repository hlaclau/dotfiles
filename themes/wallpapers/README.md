Base wallpapers of the themes. Put an image named after the theme here (any extension:
`.jpg`, `.jpeg`, `.png`, `.webp`), e.g. `tokyo-night.jpg` or `catppuccin-mocha.png`.
Names are the files in `../palettes` without `.palette`. `scripts/theme.sh` switches to it with the theme.
Without a file here the `wallpaper` line of the palette (a file in `wallpapers/`) is used.
